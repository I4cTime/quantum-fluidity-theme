# Quantum Fluidity brand assets

The mark is a "Fluid Q": a neon-tube Q whose tail flows out as a wave, with one
electron orbit passing behind the tube and two electrons riding it. The stroke
gradient is the theme's own bracket ramp (Electric Cyan -> Hyper-Violet ->
Quantum Pink from the Void palette in `src/palettes.mjs`), so the icon and the
editor share one color story.

- `mark.svg` - full mark, gradient + neon glow build (canonical geometry)
- `mark-small.svg` - simplified cut for <= 48 px (favicons, list icons)
- `mark-mono.svg` - single-color (#00D1FF) cut
- `social-card-1200x630.jpg` - Open Graph / link-preview card
- `repo-social-preview.png` - 1280x640, for GitHub -> Settings -> Social
  preview (manual upload; GitHub has no API for it). Also the README hero.
- `fonts/` + `fonts.conf` - vendored Space Grotesk and JetBrains Mono (OFL) so
  card text renders identically on every machine

The rasters (including `icon.png` at the repo root) are generated by
`npm run build:brand` (`src/build-brand.mjs`). Edit the SVGs, rerun, commit
the results. The same geometry is used across I4C Studio products: a 512 grid,
round-capped strokes, a wide + tight glow pair, and a 22.5% tile radius.
